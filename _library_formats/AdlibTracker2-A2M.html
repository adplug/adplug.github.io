Adlib Tracker 2 is a tracker written in Free Pascal. The layout is similar to "Amiga ProTracker", but with OPL2/3 instruments instead. Starting from version 9 each instrument may have rich macro capabilities (vibrato, tremolo and FM registers).

Supported file versions from 1 to 14.
