The XMI (eXtended MIDI) File Format was created by Miles Design, Inc. for their AIL (Audio Interface Library). It is based on the standard MIDI file format, but extends it with additional features such as OPL instrument support and better timing control. XMI files were widely used in DOS games during the 1990s.

Original author's homepage
The AIL2.ZIP archive contains the AIL 2.14 SDK with source code for XMI playback and tools.
